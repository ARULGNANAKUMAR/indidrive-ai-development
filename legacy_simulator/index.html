Security Architecture

🔑
API Key Policy
Keys stored server-side via environment variables only. Never in frontend code, localStorage, or URL parameters.
🛡️
Input Validation
All user input sanitized on both frontend and backend. Numeric ranges clamped. Strings stripped of HTML/script characters.
🚫
No eval() / Dynamic Script
No use of eval(), new Function(), innerHTML with user content, or dynamic script injection anywhere in the application.
⏱️
Rate Limiting
Backend rate limiting: 120 requests/minute per IP. API requests have client-side timeout of 10 seconds.
📁
File Upload Security
Allowed types: JSON, CSV only. Maximum 50 MB. Filenames sanitized. Path traversal blocked. Content treated as untrusted.
🌐
CORS Policy
CORS restricted to configured origins only. Security headers set on all responses. Stack traces never exposed to client.
